Building with AI responsibly

Learn Anthropic's four AI Fluency skills and how to use them when you write code with AI.

The 4Ds

Anthropic teaches a framework called AI Fluency with four skills, the 4Ds. Delegation is deciding what work to do with AI and what to do yourself.

Description is communicating clearly with AI. Discernment is evaluating AI outputs with a critical eye. Diligence is making sure you use AI responsibly.

Earlier modules already used these habits: choosing a tool (Delegation), writing a prompt (Description), checking answers (Discernment), and disclosing use (Diligence).

Learning to code with AI, not just getting code

Anthropic studied how university students used Claude.ai. Its data likely captures early adopters, so it may not describe every student. In the study, computer science made up 38.6% of conversations, though it is only 5.4% of U.S. bachelor's degrees. Nearly half (about 47%) of conversations were "direct," meaning the student wanted a quick resolution.

The report also raises the concern of students outsourcing thinking to AI, and says even collaborative work "still offloads significant thinking to the AI."

Anthropic's Learning mode is designed to guide students' reasoning rather than simply provide answers. If your tool and your teacher allow it, you can work the same way: ask for a hint, ask it to explain an error, and write the fix yourself.

Checking AI-written code

Discernment applies to code too. Code from AI can look right and still be wrong. Run it. Test it with an input where you know the answer.

Read each line and make sure you can say what it does; if you cannot explain it, do not rely on it, and follow your teacher's rules about what you may submit. Treat error messages as clues and look up anything unfamiliar in the official documentation for that language.

Your own commitment

Anthropic's AI Fluency for Students ends with students writing their own personal commitment to responsible AI use. You can do the same.

Write three or four sentences you would keep to: what you will use AI for, what you will always do yourself, how you will check its work, and how you will say when you used it.

Example: "I will use AI to explain ideas and check my grammar, never to write my graded work. I will test any code before I use it. I will tell my teacher when AI helped."

Change it to fit your own class rules.
