Building with AI responsibly

Learn Anthropic's four AI Fluency skills and how to apply them when you study and write code with AI.

The 4Ds

Anthropic teaches a framework called AI Fluency with four skills, called the 4Ds. Delegation is deciding what work to do with AI and what to do yourself.

Description is communicating clearly with AI. Discernment is evaluating AI outputs with a critical eye. Diligence is making sure you use AI responsibly.

Earlier modules already used these habits: choosing a tool (Delegation), writing a prompt (Description), checking answers (Discernment), and disclosing use (Diligence).

Key idea: The 4Ds help you decide what to hand off, explain what you need, judge the result, and use AI responsibly.

Learning to code with AI, not just getting code

An Anthropic study looked at how university students used Claude.ai. The study likely included more early users of AI than a typical group of students, so the results may not apply to everyone. In the study, computer science made up more than a third of conversations, though it is only 5.4% of U.S. bachelor's degrees. Nearly half (about 47%) of conversations were “direct,” meaning the student wanted a quick solution.

The report warns that even when students work through a problem with AI, the tool may still do much of the thinking.

Claude's Learning mode is designed to guide students through their own reasoning. If your tool and your teacher allow it, ask for a hint or an explanation of an error, then write the fix yourself.

Key idea: Ask AI for hints or explanations so you can work through the fix yourself.

Checking AI-written code

Discernment applies to code too. Code from AI can look right and still be wrong. Run it. Test it with an input where you know the answer.

Read each line and make sure you can say what it does; if you cannot explain it, do not rely on it, and follow your teacher's rules about what you may submit. Treat error messages as clues and look up anything unfamiliar in the official documentation for that language.

Key idea: Test AI-written code with an input you know the answer to and make sure you can explain each line.

Your own commitment

Students in the AI Fluency for Students course finish by writing a personal commitment to using AI responsibly. You can do the same.

Write a three- or four-sentence commitment: what you will use AI for, what you will always do yourself, how you will check its work, and how you will disclose when you used it.

Example: “I will use AI to explain ideas and check my grammar, never to write my graded work. I will test any code before I use it. I will tell my teacher when AI helped.”

Change it to fit your own class rules.

Key idea: Write down how you will use AI, do your own work, check results, and disclose help.
