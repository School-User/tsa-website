Copyright

The AI use disclosure below and the Resources and AI Reflection give the details. The graphics on this site (badges, logo, the home-page illustration, and six diagrams) are original CSS/SVG drawings made for this project. Technology used

This site is built with plain HTML5, CSS, and vanilla JavaScript. It uses no frameworks, libraries, templates, themes, website builders, or content management systems. Progress is saved in your browser’s local storage (localStorage).

AI use disclosure

Generative AI tools were used to build this site, as the 2027–28 guidelines allow with disclosure. Three tools were used:

  • Claude Code planned the site, drafted the text for Modules 4–6, and wrote the progress and dashboard code, the styles, and the home illustration. It also tested every page.
  • Codex drafted the pages and text for Modules 1–3, added the theme switch, rewrote the sources in MLA style, and built the practice activities.
  • Freebuff (DeepSeek) wrote the quiz code, the first Reference Page, the Demos page, the pages for Modules 5 and 6, most diagrams, and proofread the site.

The student chose the theme, the structure and the sources, opened each source to check the lesson claims against it, asked the tools to review each other’s work, and edited the result. The Resources and AI Reflection form linked above gives the full details.
